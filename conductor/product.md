# Product Definition: Frea

## Vision
Frea is an open-source, terminal-native AI coding agent and execution harness. Inspired by modern agent harness paradigms (such as OpenCode CLI and Claude Code), Frea bridges local shell environments with state-of-the-art multi-model AI reasoning, providing developers and systems engineers with a fast, autonomous, keyboard-driven companion for software engineering, system administration, and workflow automation.

## Core Value Proposition
- **Agentic Terminal Harness**: Drives autonomous or human-in-the-loop tool execution cycles—handling file system operations, code refactoring, test execution, and shell subprocesses directly inside the terminal.
- **Multi-Model Interoperability**: Agnostic AI engine supporting Google Gemini, OpenAI, Groq, and local/open-weights endpoints with seamless dynamic switching.
- **Developer-First UX / TUI**: Keyboard-centric, responsive terminal interface featuring readline multi-line editing, streaming feedback, custom status indicators, and non-intrusive loading animations.
- **Safety, Boundaries & Observability**: Monitored command execution, safety threshold filters, configurable system instructions/personas, and rotating audit/error logs.
- **Modular Extensibility**: Pluggable agent toolkits, structured configuration (`config.ini`), and custom instruction sets.

## Target Audience
- Linux power users, DevOps engineers, and software developers who prioritize command-line efficiency over heavy GUI bloat.
- Engineers seeking an open, customizable terminal agent harness alternative to proprietary CLI assistants.
