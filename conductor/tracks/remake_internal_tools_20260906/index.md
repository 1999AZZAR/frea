# Track: Remake Internal Tooling Suite from Scratch (Kamui & OpenCode Parity)

## Overview
This track rebuilds Frea's internal tool suite from the ground up, implementing the patterns established in Kamui and OpenCode. It provides robust file inspection/editing, search, background process execution, multi-step plan tracking, and OpenAI schema generation while preserving Frea's minimal dependency constraints.
