# Track: Skills and MCP Support based on OpenCode Architecture

## Overview
This track implements complete support for Skills (dynamic instruction/resource injection via `skill` tool) and Model Context Protocol (MCP) tool integration (stdio JSON-RPC client, tool schema reflection, and invocation) matching the proven architecture from OpenCode.
